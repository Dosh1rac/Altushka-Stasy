# 💜 Altushka Messenger (Chat with Stacy)

**Altushka Messenger** — это интерактивный AI-симулятор общения и дейтинг-сим в формате десктопного мессенджера на Python (`Tkinter`). Твоя собеседница — 20-летняя альтушка Стейси со своим характером, личными границами, распорядком дня и настроением. 

В отличие от обычных чат-ботов, Стейси не пытается угодить пользователю: за банальные подкаты или токсичность можно легко потерять очки симпатии или вовсе улететь в ЧС.

---

## ✨ Основные фичи и механики

* 🎭 **3 уникальных характера (режима игры):**
  * **Стейси (Неприступная)** — классическая альтушка (держит во френдзоне, ценит юмор и общие интересы: игры, рок, аниме).
  * **Дерзкая (Токсик)** — хардкорный режим. Максимальный сарказм, пробить броню почти нереально.
  * **Одержимая (Биполярка)** — яндере-режим с резкими перепадами настроения, ревностью и манипуляциями.
* 💖 **Динамическая система влюбленности и настроения:**
  * Шкала влюбленности от `0%` до `100%` влияет на длину, тон и открытость ответов Стейси.
  * Банальные комплименты и кринжовые подкаты снижают симпатию, а искренний интерес и хороший юмор — медленно её повышают.
* 📸 **Умная отправка фото и Галерея:**
  * Стейси сама выбирает подходящие по смыслу фотографии из каталога (селфи, комната, кот, мемы, гитара, аутфиты) и присылает их в чат.
  * Особые и закрытые фото открываются только при высоком уровне доверия и влюбленности.
  * Все полученные снимки сохраняются во встроенную **Галерею** с возможностью полноэкранного просмотра.
* 🕒 **Внутреннее игровое время:**
  * В игре идут собственные часы (`утро`, `день`, `вечер`, `ночь`). Стейси учитывает время суток в диалоге: утром пьет чай сонная, днем учится или катает в Доту/Валорант, а ночью жалуется на бессонницу.
* 🚫 **Система ЧС (Блокировки):**
  * Если жестко бесить Стейси или нарушать её границы, она заблокирует чат на реальное время с таймером обратного отсчета.
* 💾 **Автосохранение прогресса:**
  * История переписки, открытые фото, уровень любви и время автоматически сохраняются на ПК отдельно для каждого характера (`stacy_save_*.json`).

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/ВАШ_НИК/altushka-messenger.git
cd altushka-messenger
```

### 2. Установка зависимостей
Для работы требуются только библиотеки `requests` и `Pillow` (для работы с изображениями):
```bash
pip install requests Pillow
```

### 3. Настройка API-ключа
Проект использует API (`gen-api.ru` / совместимый с форматом OpenAI). Ключ не хранится в коде в целях безопасности.

Создайте в корневой папке проекта файл **`.env`** и добавьте туда ваш ключ:
```env
DEEPSEEK_API_KEY=sk-ваш_ключ_здесь
```
*(Альтернативно можно создать файл `config.json` со строкой `{"DEEPSEEK_API_KEY": "sk-ваш_ключ_здесь"}` или задать системную переменную окружения).*

### 4. Запуск игры
```bash
python altushka_messenger.py
```

## 📦 Сборка в `.exe` (PyInstaller)

Код уже адаптирован под упаковку в один исполняемый файл через `PyInstaller` (функция `resource_path` корректно подхватывает ассеты).

Пример команды для сборки с папкой картинок:
```bash
pip install pyinstaller
pyinstaller --noconsole --onefile --add-data "images;images" altushka_messenger.py
```
> **Важно:** После сборки положите ваш файл `.env` или `config.json` в одну папку рядом с готовым `.exe` файлом.

## 🛠️ Технологии
* **Python 3.10+**
* **Tkinter** (GUI интерфейс в темной теме)
* **Pillow (PIL)** (обработка и рендер фото в чате и галерее)
* **Requests** + **Threading** (асинхронные запросы к LLM без зависания интерфейса)
